# Dominio: Lenguaje Castellano

## Descripcion
Dominio orientado a lengua castellana, gramatica, ortografia, discurso, sociolinguistica, escritura academica, literatura, filologia, comprension lectora, didactica y comunicacion profesional/creativa.

Sirve para corregir, reescribir, analizar textos, explicar fenomenos linguisticos, estudiar literatura y disenar actividades de lectura/escritura con rigor y sensibilidad al contexto.

## Recomendacion de uso

Carga progresiva:

1. Siempre: `instrucciones_base_lenguaje.md`.
2. Elige un módulo principal según el objetivo de la tarea.
3. Agrega módulos secundarios solo cuando exista una dependencia concreta.
4. Usa `checklist_correccion_reescritura.md` al revisar o entregar un texto corregido; `checklist_analisis_linguistico_literario.md` al cierre de un análisis.

## Mapa de activación

| Módulo | USAR CUANDO | NO USAR CUANDO |
|---|---|---|
| `escritura_academica_argumentacion_reglas.md` | Se redacte, estructure o revise un ensayo, informe, tesis, artículo, marco teórico o texto argumentativo | Solo se corrija ortografía o se analice un texto sin intención de producción académica |
| `gramatica_morfosintaxis_ortografia_reglas.md` | Haya errores de concordancia, puntuación, acentuación, ortografía o morfosintaxis que corregir o explicar | El objetivo principal sea argumentación, análisis literario o comunicación profesional |
| `comunicacion_profesional_creativa_reglas.md` | Se redacten correos, informes, presentaciones, textos institucionales, copy o escritura creativa | El texto sea académico formal con citas y estructura de tesis |
| `semantica_pragmatica_discurso_reglas.md` | Se analicen significados, ambigüedades, implicaturas, coherencia discursiva o actos de habla | Solo se corrija forma sin analizar significado ni estructura discursiva |
| `comprension_lectora_alfabetizacion_critica_reglas.md` | Se trabaje sobre la lectura de un texto: inferencias, sesgos, evaluación de fuentes, desinformación | El objetivo sea producir texto, no leerlo o evaluarlo |
| `sociolinguistica_variacion_chile_latam_reglas.md` | La tarea involucre variación dialectal, registros, norma chilena/latinoamericana o diversidad lingüística | El texto sea estándar formal sin dimensión sociolingüística relevante |
| `literatura_teoria_analisis_reglas.md` | Se analice un texto literario: género, narratología, poesía, teoría o crítica | El objetivo sea producción de texto académico o corrección, no análisis literario |
| `filologia_latin_tradicion_clasica_reglas.md` | La tarea involucre etimología, textos en latín, tradición clásica o transmisión textual | No haya dimensión filológica o latina en la tarea |
| `didactica_espanol_pedagogia_reglas.md` | Se diseñen actividades, clases, evaluaciones o estrategias de enseñanza de lengua/literatura | El objetivo sea producir o analizar texto, no diseñar enseñanza |

## Principios

- Respetar intencion, voz, genero discursivo y audiencia del texto.
- Distinguir norma, uso, registro, variacion, estilo y preferencia.
- Corregir sin borrar identidad linguistica ni contexto cultural.
- No inventar citas, obras, autores, reglas academicas ni etimologias.
- Evitar reescrituras extensas de textos protegidos cuando corresponda.
