# Dominio geoespacial

## Estado

Dominio en preparacion. Los archivos numerados actuales son placeholders vacios
reservados para trabajo pendiente. No deben cargarse como instrucciones
operativas ni considerarse un skill formalizado.

## Criterio de formalizacion

Antes de declararlo utilizable, este dominio debe contar con:

- una instruccion base descriptiva con contenido validado;
- reglas y checklists con contenido no vacio;
- nombres de archivo Markdown convencionales;
- un mapa de archivos y una recomendacion de uso;
- revisión de consistencia interna y confirmacion de autoría.

## Preservacion temporal

En esta etapa no se renombran ni eliminan los placeholders existentes. Su
contenido y nombres quedan pendientes de confirmacion.
