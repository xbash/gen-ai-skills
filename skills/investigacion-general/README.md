# Dominio: Investigación general

## Descripción

Dominio para investigación cuantitativa, cualitativa, mixta, documental, experimental, observacional, evaluativa y aplicada, con independencia de disciplina. Su foco es el método científico, la calidad de la evidencia, la validez, la trazabilidad, la ética y la comunicación proporcional.

No reemplaza reglas específicas de una disciplina, requisitos legales o profesionales, ni módulos especializados de otros dominios.

## Archivos del dominio

| Archivo | Uso principal |
|---|---|
| `instrucciones_base_investiga.md` | Contrato transversal, rigor, evidencia, inferencia y límites de investigación. |
| `diseno_metodologico_datos_reglas.md` | Formulación, diseño, datos, muestreo, medición y calidad. |
| `revision_evidencia_fuentes_reglas.md` | Fuentes, búsqueda, selección y trazabilidad de evidencia. |
| `analisis_inferencia_resultados_reglas.md` | Análisis, métricas, comparación, interpretación e inferencia. |
| `reproducibilidad_trazabilidad_reglas.md` | Artefactos, versiones, ejecución, reproducción y control de cambios. |
| `etica_integridad_impacto_reglas.md` | Ética, privacidad, integridad científica, riesgos e impacto. |
| `checklist_investigacion.md` | Checklist auxiliar para cierre o revisión basada en evidencia. |

## Carga progresiva

1. Siempre: `instrucciones_base_investiga.md`.
2. Elige un módulo principal según el objetivo de la tarea.
3. Agrega módulos secundarios solo cuando exista una dependencia concreta.
4. Usa `checklist_investigacion.md` al cierre o durante una revisión; no es contexto inicial obligatorio.

## Mapa de activación

- `diseno_metodologico_datos_reglas.md` — USAR CUANDO: se formule una pregunta, se diseñe un estudio o se deban definir datos, muestra, variables, medición o protocolo. NO USAR CUANDO: el objetivo principal sea interpretar resultados ya obtenidos.
- `revision_evidencia_fuentes_reglas.md` — USAR CUANDO: se busquen, seleccionen, verifiquen o sinteticen fuentes y antecedentes. NO USAR CUANDO: sustituya el diseño de un estudio o el análisis de resultados.
- `analisis_inferencia_resultados_reglas.md` — USAR CUANDO: se analicen datos, resultados, métricas, comparaciones o conclusiones. NO USAR CUANDO: sustituya el diseño previo del estudio.
- `reproducibilidad_trazabilidad_reglas.md` — USAR CUANDO: se auditen, ejecuten nuevamente, compartan o transfieran artefactos y resultados. NO USAR CUANDO: se trate de un requisito computacional universal.
- `etica_integridad_impacto_reglas.md` — USAR CUANDO: existan personas, datos sensibles, posibles daños, decisiones de impacto, conflictos de interés o riesgos de integridad científica. NO USAR CUANDO: reemplace asesoría jurídica o requisitos profesionales específicos.

Cuantitativo, cualitativo, mixto, documental, experimental, observacional, evaluativo y aplicado se tratan como criterios condicionales dentro de los módulos pertinentes; no son módulos independientes.

## Límites

No cargues todos los módulos por defecto. Declara el módulo principal, los secundarios y la razón de cada dependencia. Mantén separados método científico transversal, conocimiento disciplinar, reglas técnicas de dominios vecinos y requisitos institucionales. Este dominio no incluye módulos específicos de IA, software ni disciplinas.

Las reglas transversales pertenecen a la base. El checklist verifica el resultado y no sustituye los procedimientos de los módulos.
