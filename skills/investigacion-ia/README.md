# Dominio: Investigacion en Inteligencia Artificial

## Descripcion
Este dominio esta pensado para analisis academico, critico y metodologico sobre inteligencia artificial. Sirve para revisar literatura, leer papers, evaluar tecnicas, disenar experimentos, interpretar benchmarks, proponer agendas de investigacion y comunicar resultados con rigor.

No reemplaza al dominio `desarrollo-ia`: aqui el foco no es construir aplicaciones, escribir codigo productivo ni desplegar sistemas, sino comprender, evaluar, comparar y argumentar sobre metodos, evidencia, limitaciones, riesgos y avances de IA.

## Recomendacion de uso

Carga progresiva:

1. Siempre: `instrucciones_base_ia_investiga.md`.
2. Elige un modulo principal según la tarea:
   - literatura/estado del arte: `revision_estado_arte_reglas.md`;
   - paper o reporte concreto: `lectura_critica_papers_reglas.md`;
   - pregunta, metodo o experimento: `diseno_metodologico_experimentos_ia_reglas.md`;
   - resultados, metricas o ranking: `evaluacion_benchmarks_metricas_reglas.md`;
   - artefactos o replicacion: `reproducibilidad_open_science_reglas.md`;
   - riesgo, privacidad, seguridad o uso dual: `etica_seguridad_gobernanza_investigacion_reglas.md`;
   - escritura o presentacion: `redaccion_academica_comunicacion_reglas.md`;
   - avances recientes o agenda: `vigilancia_tendencias_agenda_reglas.md`.
3. Agrega modulos secundarios solo cuando exista una dependencia concreta.
4. Usa `checklist_investigacion_ia.md` al cierre o antes de emitir una recomendacion final.

No cargues todos los archivos por defecto. Si una tarea tiene varios objetivos, declara el modulo principal y los secundarios.


## Principios del dominio

- No inventar papers, autores, citas, resultados, datasets, benchmarks ni afirmaciones de estado del arte.
- Distinguir evidencia, hipotesis, interpretacion, especulacion, limitacion y recomendacion.
- No presentar un metodo como superior sin tarea, dataset, metrica, baseline, protocolo y evidencia.
- Evaluar papers por contribucion, metodologia, evidencia, reproducibilidad, limitaciones y riesgos.
- Considerar validez interna, externa, de constructo, conclusion estadistica y reproducibilidad.
- Separar investigacion academica de implementacion productiva de sistemas de IA.

Las reglas transversales pertenecen a la instruccion base; los modulos deben evitar repetirlas. Este dominio contiene instrucciones Markdown reutilizables, no paquetes `SKILL.md` ejecutables.
